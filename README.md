# 🧵 Handicraft Buy & Selling Platform

A full-stack **MERN** web application designed to connect handicraft sellers and buyers in one online marketplace.  
This system helps promote local handmade products and supports small businesses through digital marketing, secure payments, and easy online sales.

---

## 🚀 Features

### 👤 User Side
- User Registration & Login  
- Browse handicraft products  
- Smart search & filtering  
- Add to cart  
- Place orders  
- Order history tracking  

---

### 🛍️ Seller Side
- Add / Edit / Delete products  
- Manage stock  
- Upload images  
- View sales  

---

### 💳 Payment Management (My Role)
- Secure online payment integration  
- Multiple payment methods
- Transaction tracking & history  
- Refund and cancellation handling  
- Invoice generation  

---

### 📢 Marketing & Promotion
- Promotion management  
- Featured products  
- Discounts & offers  
- Customer engagement tools  
- Analytics for sales performance  

---

### ⚙️ System Features
- Responsive UI  
- Secure authentication (JWT)  
- REST API  
- Dynamic search bar  
- PDF report generation  
- MongoDB database
