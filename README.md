# 🧵 CraftLink – Handicraft Buying & Selling System 🎨🛍️

Welcome to **CraftLink**, a full-stack **MERN-based marketplace platform** developed as part of the **IT2080 Information Technology Project**.  
This system connects artisans and customers through a seamless digital ecosystem for **buying, selling, payments, promotions, and delivery management**.

It is designed with a modular architecture where each team member contributed to a specific domain, ensuring scalability, maintainability, and real-world system design practices.

---

## 🌟 Core Modules & Role Allocations

The development of CraftLink is divided into five major functional modules, each implemented by a dedicated contributor:

---

### 👤 Role 1: User Management Lead
- Core authentication and identity management module  
- Secure user registration and login (JWT-based authentication)  
- Role-based access control (Admin / Seller / Buyer)  
- User profile management (view / update / delete)  
- Account lifecycle and session handling  

---

### 🛍️ Role 2: Product & Cart Manager
- Complete product lifecycle management (CRUD operations)  
- Product image upload and management  
- Category-based filtering and advanced search system  
- Shopping cart operations (add / update / remove items)  
- Smooth product browsing experience for users  

---

### 💳 Role 3: Payment & Transactions Specialist
- Secure payment processing system (Bank Transfer / Cash on Delivery)  
- Bank slip upload and verification workflow  
- Transaction history tracking and monitoring  
- Refund and cancellation handling system  
- Automated invoice and receipt generation  

---

### 🚚 Role 4: Delivery & Order Tracking Coordinator
- Order confirmation and delivery assignment system  
- Real-time delivery status tracking  
- Delivery report generation for management  
- Automated customer notifications for order updates  

---

### 📢 Role 5: Promotion & Customer Engagement Manager
- Customer feedback and complaint handling system  
- Discount and promotional campaign management  
- Seasonal offers and marketing campaigns  
- Customer engagement and interaction features  

---

## 🛠️ Technology Stack

CraftLink is built using a modern **MERN stack architecture** with additional tools for development efficiency and scalability.

---

### 💻 Frontend
- React.js (Component-based UI development)  
- React Router (Navigation & routing)  
- HTML5, CSS3, JavaScript  
- Responsive UI with dynamic search & filtering  

---

### ⚙️ Backend
- Node.js (Server runtime environment)  
- Express.js (REST API framework)  
- JWT Authentication (Security layer)  
- RESTful API architecture  
- Postman (API testing & validation)  

---

### 🗄️ Database
- MongoDB (NoSQL database)  
- Flexible schema design for e-commerce workflows  
- Optimized collections for scalability  

---

### 🧰 Tools & Environment
- Git & GitHub (Version control)  
- VS Code (Development environment)  
- Postman (API testing & debugging)  

---

## 🚀 Getting Started

Follow these steps to run the project locally.

---

### ⚙️ Backend Setup
```bash
cd backend
npm install
npm start
```

📌 Backend runs at:
```
http://localhost:5000
```

---

### 💻 Frontend Setup
```bash
cd frontend
npm install
npm start
```

📌 Frontend runs at:
```
http://localhost:3000
```
